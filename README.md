# Turn-based-RPG

## 1. Project Introduction

Turn-based-RPG is a Java-based turn-based role-playing game.

Players can select characters, fight against monsters, use different skills and items, and improve their characters through battles.

This project is developed as a Software Engineering course final team project.

## 2. Main Features

- Character Selection
- Character Status Management
- Turn-Based Battle System
- Skill System
- Monster System
- Item and Inventory System
- Experience and Level-Up System
- Battle History

## 3. Development Environment

- Programming Language: Java
- Development Tool: IntelliJ IDEA / Eclipse
- Version Control: Git and GitHub
